# Surface: README

`README.md` at the repo root is a **symlink** to `packages/evlog/README.md`. Edit the package file. Editing the symlink target through the root path is the same file, but referring to the root path in a PR hides what changed.

## What it owes its reader

Someone on npm or GitHub deciding in thirty seconds whether to keep reading. It answers three things in order:

1. What is this, in one sentence that survives the substitution test.
2. What does the code look like, in the smallest complete example that runs.
3. Where do I go next: install, docs, the framework list.

Everything else is a link. A README that grows into documentation is documentation nobody versioned.

## Rules that bite here

- **U-04** hardest: badges and one-line claims are the least verifiable prose in the repo.
- The framework list and the adapter list go stale silently. Every content pass over the README checks both against `packages/evlog/package.json#exports`.
- Sections generated by automd (`.github/automd.json`) are regenerated, not hand-edited. Check for the markers before editing a block.
