# The landscape

One file per tool evlog gets compared to. Each holds what that tool actually does, so `U-12` findings are checked rather than remembered.

The reader who knows the other tool is the reader these pages are written for. One unfair comparison and they stop believing the rest of the page, including the parts that were true.

## How to use a dossier

Before writing or approving any sentence that names another logger:

1. Find the claim in the dossier. If it is not there, the claim is unverified and does not ship as written.
2. Check the `Checked:` date. Older than six months, treat every line as a hypothesis and re-read the tool's own docs before citing it.
3. Carry the link into the page. `U-04` wants a mechanism, a number, or a source, and a comparison has a source by definition.

## How to keep one true

A dossier is refreshed from the tool's own documentation and changelog, never from memory and never from what a competitor's marketing says about it. When a line changes, move the old line to `Was:` with its date rather than deleting it, so a page still carrying the old claim is findable.

The failure mode is specific and it is not laziness: a dossier written from what you remember is fluent, confident, and wrong in the details that matter to the one reader who knows the tool. Its reporter list is plausible. Its delivery model is plausible. Neither was read. Open the tool's own documentation and find the claim there before a dossier states what it ships.

The scanner cannot check any of this. It can only tell you a sentence makes a claim about pino and carries neither a number nor a link.
