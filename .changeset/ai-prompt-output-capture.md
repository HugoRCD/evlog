Add `prompt` and `output` options to the AI SDK integration. Each one independently captures one direction of the model call: `prompt: true` adds `ai.prompt` (the formatted prompt sent to the first model call) and `output: true` adds `ai.output` (the text generated by the last model call). Both accept `maxLength` truncation and a `transform` hook for redaction. Off by default.
